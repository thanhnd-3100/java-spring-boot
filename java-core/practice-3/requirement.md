The police sector needs to manage the means of transport including: cars, motorbikes, trucks. Each category includes information: vehicle number, manufacturer, year of manufacture, vehicle color and vehicle owner. In there:
– Cars manage more attributes: number of seats, engine type
– Motorcycles manage more attributes: capacity
– Trucks manage more attributes: tonnage
– Vehicle owners manage information: ID number, full name, email
With your OOP knowledge learned, write a program in the Java programming language that fulfills the following requirements

Requirement 1: Build classes to manage the above facilities effectively

Requirement 2: The program performs the following tasks:
- More means of transport
- Search for transport by vehicle number
- Find the vehicle owner's vehicle with the corresponding cmnd number
- Delete all vehicles of any manufacturer
- Indicate which manufacturer has the most vehicles under management
- Sort vehicles by number of vehicles in descending order
- Statistics of each vehicle type, how many vehicles are being managed
Some of the rules of the program are as follows
- Each car has a unique car number that does not match and has exactly 5 characters
– Manufacturers only include: Honda, Yamaha, Toyota, Suzuki
– The year of manufacture must be less than or equal to the current year and greater than 2000
– The ID number must be exactly 12 numbers and each car owner has a unique identity card number
- Email must be in the correct format
